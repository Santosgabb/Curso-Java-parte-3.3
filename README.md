# Curso de Java: Orientação a Objetos - Parte 3.3 ☕

Exercícios práticos focados no funcionamento de métodos com valores de retorno e passagem de parâmetros em Java.

---

## 📌 Conteúdos Abordados

* **Métodos com Retorno**: Utilização da palavra-chave `return` e definição dos tipos de dados retornados (`double`, `int`, etc.).
* **Passagem de Parâmetros**: Recebimento de argumentos nos métodos para cálculos dinâmicos.
* **Encapsulamento de Lógica**: Delegação de regras de cálculo para a própria classe de modelo.
